# Опора — контекст проекта

Телеграм-бот и мини-апп: трекер ежедневных практик. Одна цель, шесть коротких
действий в день, слова поддержки в нужный момент. Для личного круга (автор, муж,
несколько близких), не публичный продукт.

Идеи взяты из Джона Кехо («Подсознание может всё») и Вадима Зеланда
(«Трансерфинг реальности»), но **фразы приложения — свои**, без фирменных терминов.
Цитаты допускаются отдельным жанром: короткие, уместные, всегда с указанием автора,
и только те, в точности которых есть уверенность (классики, проверенные тексты).
Мысли современных психологов подаются как «по мотивам», а не в кавычках.

## Куда идёт (сентябрь 2026)

Приложение должно стать другом, психологом и помощником, куда хочется заходить
каждый день. Мотивация — протянутая рука, а не хлыст. Этапы: правки после тестов →
несколько целей → библиотека практик и знаний → взгляд назад → ИИ-агент (диалог
на старте, анализ поведения, персональные фразы) → лёгкие расслабляющие мини-игры.

## Главный принцип

Человеку тяжело заставить себя во что-то поверить, и приложение этого не требует.
Оно трекает **действия**, а не убеждения. Никаких «поверь», «визуализируй желание»,
«мысли материальны». Действие на минуту — и дальше по своим делам.

## Файлы

| Файл | Что внутри |
|---|---|
| `bot.py` | Бот (aiogram), веб-сервер мини-аппа, API, SQLite, распознавание спада, уведомления |
| `packs.py` | Десять наборов фраз по направлениям + подбор по словам цели. Самый правимый файл |
| `content.py` | Практики дня, запасной набор фраз, шаги «минуты тишины» |
| `generator.py` | Персональная генерация фраз через Claude API. Включается только при наличии `ANTHROPIC_API_KEY`, иначе не трогается |
| `index.html` | Мини-апп, один файл: разметка, стили, скрипт |

## Как это работает

**Постановка цели.** Первый экран — десять кнопок направлений одним словом:
Деньги · Тело · Дело · Покой · Любовь · Карьера · Учёба · Дом · Творчество · Привычка.
Человек жмёт одну, пишет цель своей строкой и одну деталь того дня, один раз
выбирает род обращения. Подсказки в полях берутся из выбранного направления
(`example`, `example_vision` в паке) — примеры общие, не под одного человека.
Выбранное направление решает, какой набор фраз подставится — промах исключён.
Подбор по словам цели (`match_pack`) остался запасным, на случай если кнопка не дошла.

**Несколько целей.** До трёх одновременно (`MAX_GOALS`), все в таблице `goals`.
Одна — главная (`is_main`): её слова задают фразы дня, подсказку «сказать вслух»
и уведомления. Колонки `users.goal/track/vision/pack/started_at` — зеркало главной
цели, его держит `mirror_main`; старый код читает оттуда и о нескольких целях не
знает. Остальные цели — тихие кнопки под главной в мини-аппе, тап делает цель
главной; «+ ещё цель» открывает ту же форму без вопроса о роде. «Цель достигнута»
закрывает главную, главной становится следующая. У каждой цели свой пак фраз
(с ключом — своя генерация, значит своя строка в `usage`).

**День.** Шесть практик, одинаковых для любой цели: побыть в готовом дне, сказать
вслух, один шаг, отпустить важность, три вещи, картинка на завтра. У трёх есть поле
заметки. Разницу между целями делают не практики, а слова вокруг них.

**Рубеж отчаяния** (`in_low`). Срабатывает, если человек нажал «сегодня не идёт»
(событие `hard`), открывал минуту тишины (`sos`), или два пустых дня подряд после
живой серии. Тогда планка дня падает с трёх отметок до одной, серия не рвётся,
а тексты меняются на поддерживающие.

**Минута тишины.** Открывается тихой ссылкой «нужна опора» внизу экрана (и ещё одной
в карточке дня, когда человек на спаде) — плавающей кнопки поверх контента нет,
тестеры жаловались на навязчивость. Внутри: длинный выдох (сорок секунд), назвать
чувство одним словом, вернуть ощущение контроля.

**Уведомления.** Максимум два в день: окна 8:30–9:00 и 21:00–21:30 по Москве,
проверка раз в минуту. Отправленное помнится в `events` (`push:morning`,
`push:evening`) — перезапуск на Railway не сбивает. Вечернее не приходит, если день
уже закрыт по планке. `/tikho` — молчание на три дня. Ночью тишина всегда.
Каждый заход в мини-апп пишется событием `open` — это сырьё для анализа, на какое
уведомление человек откликается.

## Тон текстов — не нарушать

- Повелительное наклонение по умолчанию («выдохни», «побудь») — в нём нет рода,
  подходит и мужчине, и женщине без отдельных вариантов
- Без восклицательных знаков, без «срочно», «успей», «не забудь», без смайлов
- Не стыдить за пропуски, не считать провалы, не обещать чудо
- Не утверждать, что мысли сами меняют внешние события. Только внимание, спокойствие, действие
- Сначала действие на минуту, потом смысл
- Называть состояние, а не отрицать его: «похоже, день давит» — да, «всё хорошо» — нет
- В строках раздела `low` можно ставить `{count}` — подставится «23 отметки»
  с правильным склонением (`plural_marks` в `bot.py`)

## Деплой

GitHub `litplit09-cell/opora` → Railway, автодеплой при пуше в `main`.
Старт-команда `python bot.py` из `Procfile`.

Переменные Railway:

```
BOT_TOKEN=токен от BotFather
DB_PATH=/data/opora.db
TZ_NAME=Europe/Moscow
WEBAPP_URL=https://web-production-d1088.up.railway.app
```

**Том на `/data` обязателен** — без него база стирается при каждом деплое.

`ALLOWED_IDS` намеренно не задан: бот открыт для всех, кто его найдёт — это
решение автора, белый список не возвращать даже с ключом. Расходы на ИИ
контролируются лимитом трат в консоли Anthropic и учётом в таблице `usage`
(каждый запрос: модель, токены, доллары). Команда `/lyudi` доступна только
`OWNER_ID` и показывает людей, активность и расход. Дальше планируется платная
подписка — расход должен считаться на человека.

```
ANTHROPIC_API_KEY=ключ с platform.claude.com
OWNER_ID=telegram-id автора
CLAUDE_MODEL=claude-opus-5   (необязательно; по умолчанию Opus 5)
```

## Частые правки

**Добавить или изменить фразу** — `packs.py`, обычные строки в списках
`daily`, `low`, `sos_close`, `morning`, `evening`.

**Новое направление** — скопировать блок в `PACKS`, поменять `label`
(одно слово для кнопки), `keywords` и тексты. Кнопка появится сама,
вёрстку трогать не нужно.

**Изменить практики дня** — список `PRACTICES` в `content.py`. Мини-апп
подхватит: он рисует то, что пришло от сервера.

**Время уведомлений** — функция `reminders` в `bot.py`.

## Чего избегать

- Не добавлять геймификацию: очки, уровни, «ты пропустил 2 дня 😔». Это ровно то,
  от чего приложение уходит. Мини-игры допустимы только расслабляющие, без счёта
  и без проигрыша
- Не наращивать число уведомлений
- Цитаты — только с автором и только уверенные; выдуманных или приблизительных
  цитат не бывает
- Не мучить человека вопросами при постановке цели. Диалог с ИИ-агентом — по желанию,
  а не обязательный шаг; простая цель («похудеть на 2 кг») остаётся простой
- Примеры в подсказках — общие, не про одного человека (никаких «литеек»)
- Формы прошедшего времени и прилагательные в фразах несут род («сорвался»,
  «спокоен», «обязан») — переписывать безлично
