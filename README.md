# Опора

Телеграм-бот и мини-апп: одна цель, шесть коротких действий в день и пара слов тогда,
когда они нужны. Верить ни во что не требуется — нужно отмечать сделанное.

## Как устроено

**Направление — одним словом, цель — своими.** На первом экране десять кнопок:
Деньги · Тело · Дело · Покой · Любовь · Карьера · Учёба · Дом · Творчество · Привычка.
Человек выбирает одну, пишет цель одной строкой («моё дело работает и кормит меня»)
и одну деталь того дня («первый постоянный клиент вернулся сам»). Подсказки в полях
меняются под выбранное направление. Один раз указывает род обращения.

**Фразы берутся из выбранного направления.** В `packs.py` десять наборов, у каждого
свои мысли дня, поддержка на спаде, концовки «минуты тишины» и аффирмация. Выбранная
кнопка решает всё — промахнуться невозможно. Если направление почему-то не пришло,
работает запасной подбор по словам цели, а если и он пуст — универсальный набор.
Ничего подключать не нужно, работает сразу и бесплатно.

Если в переменных появится `ANTHROPIC_API_KEY`, вместо готового набора будет
собираться персональный: один запрос к Claude при постановке цели, дальше он лежит
в базе и API больше не дёргается. Это нужно для публичной версии, для своих — нет.

**Практики одинаковы для любой цели:** побыть в готовом дне, сказать вслух, один шаг,
отпустить важность, три вещи, картинка на завтра. Разницу делают слова вокруг них.

**Рубеж отчаяния.** Приложение видит спад по двум пустым дням после живой серии либо по
нажатию «сегодня не идёт». Тогда планка падает до одного пункта, серия не рвётся,
а тексты меняются на поддерживающие — без «соберись» и счётчиков вины.

**Минута тишины.** Тихая ссылка «нужна опора» внизу: дыхание с длинным выдохом,
называние чувства, возврат опоры. Это то, что реально снижает напряжение за минуту.

**Уведомления.** Максимум два в день: утром в 8:30 и вечером в 21:00. Вечернее не
приходит, если день уже закрыт. `/tikho` — молчание на три дня. Ночью тишина всегда.

## Файлы

- `bot.py` — бот, API мини-аппа, база, распознавание спада, уведомления
- `packs.py` — десять наборов фраз, кнопки направлений и запасной подбор по словам
- `content.py` — практики, запасные фразы, тексты SOS
- `generator.py` — персональная генерация, включается только при наличии ключа
- `index.html` — мини-апп

## Деплой

**1. BotFather:** `/newbot`, сохранить токен. Свой ID — у `@userinfobot`.

**2. GitHub:** приватный репозиторий, загрузить файлы.

**3. Railway:** New Project → Deploy from GitHub repo. Переменные:

```
BOT_TOKEN=токен_от_BotFather
ALLOWED_IDS=твой_id,его_id
DB_PATH=/data/opora.db
TZ_NAME=Europe/Moscow
```

Settings → Networking → Generate Domain, полученный адрес добавить как `WEBAPP_URL`,
затем передеплоить.

**4. Диск:** Settings → Volumes → New Volume, точка монтирования `/data`.
Без него база сотрётся при первой же правке кода.

## Команды

- `/day` — открыть сегодняшний день
- `/stats` — цели, серия и 14 дней одной строкой
- `/nedelya` — оглянуться на неделю своими заметками
- `/frazy` — пересобрать фразы под главную цель
- `/tikho` — тишина на три дня
- `/lyudi` — только для владельца (`OWNER_ID`): люди, активность, расход на ИИ

Любой текст в чат — разговор с ботом (нужен `ANTHROPIC_API_KEY`): поможет
сформулировать цель, поговорит, когда тяжело.

## Правки текстов

Все фразы — в `packs.py`, обычными строками: дописать, убрать, переписать под себя.
Новое направление — скопировать блок, поменять `label` (одно слово для кнопки),
`keywords` и тексты. Кнопка появится сама.
Подписи практик и тексты «минуты тишины» — в `content.py`.

Тон везде один: повелительное наклонение (в нём нет рода, работает и для него, и для
неё), без восклицательных знаков, без «срочно» и «успей», без счётчиков вины.
В строках раздела `low` можно ставить `{count}` — подставится «23 отметки»
с правильным склонением.
